# 실패 사례

실제로 틀렸던 것만 적는다. 있을 법한 이야기는 넣지 않는다. 모델 프롬프트에 이 문서가 통째로 들어가므로,
여기 적힌 패턴은 모델이 같은 자리에서 다시 틀리지 않게 하는 데 쓰인다.

각 항목은 이렇게 적는다: 무엇이 틀렸나 / 왜 그랬나 / 지금은 어떻게 막나.

---

## 1. 이름을 줄여 뽑는다

**틀린 것.** "박업체 과장님이 부산 사상에서 차로 오시면서 김해시청 앞에서 이업체 기사님을 태우고 오십니다"를
넣었더니 참석자 이름이 `["업체", "업체"]` 로 나왔다. 두 사람이 같은 이름이 되어 화면에서 구분이 안 됐다.

**왜.** 학습 데이터 561개 이름이 전부 "나", "업체", "과장님" 같은 일반 호칭이었고 성이 붙은 형태가 0건이었다.
모델은 본 적 없는 형태를 아는 말로 뭉갠다.

**지금.** 뽑은 이름이 원문에 그대로 있는지 코드가 본다. 원문에서 이름 앞에 한글이 더 붙어 있으면 잘린 것으로
보고 대형 모델로 넘긴다 (`slot_model.check_names`). 학습 데이터에도 성·직함이 붙은 호칭 150건을 넣었다.
뒤는 보지 않는다. 한국어는 이름 뒤에 조사가 바로 붙어서("과장님이", "동료는") 뒤까지 막으면 멀쩡한 이름도 걸린다.

## 2. 출입 절차가 있다고 단정한다

**틀린 것.** 절차 이야기가 한 마디도 없는 문장에서 `access.required: true` 를 내놓았다. 없는 절차 소요를
15분씩 빼서 출발 시각이 그만큼 일러졌다.

**왜.** 학습 데이터에서 사무실·건물이 나오는 문장은 대개 절차가 있었다. 장소 이름만 보고 기울었다.

**지금.** 단서가 없으면 `access` 를 통째로 비우고 `missing` 에 `access.required` 를 적어 되묻는다.
슬롯이 비어 오면 파이프라인이 계산으로 넘어가지 않고 질문을 돌려준다 (5절 1-2).

## 3. 합류 지점을 역으로 잡는다

**틀린 것.** 출입 절차가 있는 방문인데 "OO역에서 먼저 만나 같이 가자"를 그대로 집결지로 잡았다.
역에서 만나도 절차는 1층에서 시작되므로, 먼저 도착한 사람이 역에서 기다리는 시간만 늘었다.

**왜.** 사람이 말한 문장을 판단 없이 받아들였다.

**지금.** 절차가 있으면 후보 1순위를 절차가 시작되는 자리로 잡는다 (`rendezvous_is_procedure_start`).
사용자가 말한 자리는 후보로 남기되 왜 1순위가 아닌지 이유를 붙인다.

## 4. 없는 제약을 만들어 넣는다

**틀린 것.** 장비 이야기가 없는 문장에 `constraints: ["luggage"]` 를 넣었다. 그 값 때문에 준비물에
장비 반입 신고가 붙었다.

**지금.** 제약은 문장에 근거가 있을 때만 넣는다. 확신이 없으면 넣지 않는다. 빠뜨린 제약은 사용자가
다시 말하면 되지만, 없는 제약은 준비물과 이동수단 판단까지 흔든다.

## 5. 자리 이름을 검색어로 만든다

**틀린 것.** 후보를 찾을 때 "OO빌딩 정문" 으로 검색해 0건이 나왔다. 지도에 그런 이름의 장소는 없다.

**지금.** 검색어는 "정문", "출입구" 처럼 짧게 두고 자리는 좌표와 반경으로 좁힌다. 한 말로 비면
다음 말로 넘어간다 (`search_places` 의 검색어 목록).

## 6. 같은 이름이 여러 곳에 있다

**틀린 것.** "마산역" 을 찾으면 창원과 고양 두 곳이 나온다. 목적지를 모르면 검색 순위 1등을 그대로 믿게 된다.

**지금.** 목적지를 먼저 찾고 그 좌표를 기준으로 같은 지역 것만 남긴다 (`geo._pick`). 그래도 애매하면
확신도를 낮춰 사용자에게 핀을 확인받는다. 지어낸 좌표로 계산까지 가는 것보다 한 번 묻는 쪽이 싸다.

## 7. 자정을 넘기면 날짜가 사라진다

**틀린 것.** 밤 약속에서 출발이 전날 23:05 인데 "23:05" 만 돌려주면 어느 날인지 알 수 없다.

**지금.** 역산 결과에 `day_offset` 을 같이 준다. 전날이면 -1 이다. 첫차·막차도 24시를 넘겨
"24:37" 처럼 오므로 "00:37 + 다음 날" 로 나눠 준다.

## 8. 막차를 넘긴 경로를 답으로 준다

**틀린 것.** 작업이 새벽에 끝나는데 대중교통 경로를 그대로 답으로 내놓았다. 그 시각에는 그 경로가 없다.

**지금.** 늦게 끝나는 약속이면 첫차·막차를 먼저 본다. 막차를 넘기면 대중교통 경로는 성립하지 않는다고 말한다.

## 도구 쪽에서 걸렸던 것

모델이 아니라 바깥 API 때문에 실패한 것들이다.

| 무엇 | 증상 | 대응 |
|---|---|---|
| 대중교통 API 호출 제한 | 연속으로 부르면 429 | 한 줄로 세우고, 429 면 쉬었다 다시 부른다 |
| 경로 조회 실패 | 한 명의 경로가 없으면 전체가 멈춤 | 그 사람만 빼고 나머지로 계산하되, 빠진 사람을 화면에 알린다 |
| 시각표 API | 이른 순서로 주지 않는다 | 첫 행을 첫차로 보지 않고 min·max 로 고른다. `00:00:00` 더미 행은 뺀다 |
| 판정 모델 | 형식을 어기거나 비용 상한을 넘김 | 한 번 재시도하고, 그래도 안 되면 규칙 점수 순서로 채운다 |
